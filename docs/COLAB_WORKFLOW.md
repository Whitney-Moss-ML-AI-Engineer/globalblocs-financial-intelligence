# Google Colab Workflow

Use Colab for reproducible research:
1. Install the repository package.
2. Load SEC, yfinance, macro, and regulatory data through source contracts.
3. Run provenance and data-quality checks.
4. Query the 350-metric knowledge base.
5. Build point-in-time ML features.
6. Run statistics and hypothesis tests.
7. Run walk-forward LSTM/Transformer experiments.
8. Export CSV/JSON datasets for the dashboard.

Production calculations belong in src/globalblocs; notebooks are research and demonstration surfaces.
