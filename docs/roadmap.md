# Development Roadmap

## Phase 0 — Foundation
Systems engineering baseline, requirements, architecture, source registry, package structure, and testing.

## Phase 1 — Economic Cycle
FRED/BEA/BLS ingestion → validation → macro features → cycle/regime models → dashboard.

## Phase 2 — Corporate Intelligence
SEC EDGAR/XBRL → filing normalization → financial features → corporate health models.

## Phase 3 — Banking Intelligence
FDIC/Federal Reserve/OCC → bank features → capital/liquidity/credit analytics.

## Phase 4 — Markets & Credit
Treasury/FINRA/CFTC → market and credit indicators → risk models.

## Phase 5 — AI Research
Financial and regulatory documents → retrieval → evidence-backed research assistant.

## Phase 6 — Integrated Intelligence
Cross-domain features → models → systemic-risk analytics → API/dashboard → MLOps monitoring.
