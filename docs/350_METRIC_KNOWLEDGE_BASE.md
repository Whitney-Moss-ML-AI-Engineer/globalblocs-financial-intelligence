# GlobalBLOCS 350-Metric Knowledge Base

The production catalog contains exactly 350 metadata records:
- Return & Performance: 100
- Portfolio & Risk: 100
- Risk-Adjusted Performance: 50
- Quantitative Finance & Financial Engineering: 100

Each record carries identity, definition, purpose, formula/implementation reference, required data, source-validation hooks, visualization profile, statistical hooks, ML feature eligibility, LSTM/Transformer eligibility, and limitations.

The visualization recommendation is advisory. The universal visualization library remains selectable, while a compatibility engine checks the supplied dataset schema.

Analytical chain:
Source -> Provenance -> Validation -> Metric -> Visualization -> Statistics -> Feature Store -> Model -> Evaluation -> Research Output.
