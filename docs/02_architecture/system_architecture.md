# System Architecture

Official Sources → Ingestion → Bronze/Raw → Validation & Standardization → Silver → Feature Engineering → Gold → Statistical/ML Analytics → Risk & Intelligence Engines → Retrieval/AI → Dashboard/API → Human Decision Support

## Principles

Authoritative sources remain the evidence layer. Deterministic transformations are reproducible. Models are versioned and evaluated. AI outputs require retrieval-backed evidence. Human review remains part of consequential interpretation.
