# ML/AI Architecture

## Predictive
Regression, classification, time-series forecasting, survival analysis, probability estimation.

## Unsupervised
Clustering, PCA, anomaly detection, regime detection.

## Deep Learning
LSTM, GRU, Transformers, autoencoders.

## Generative AI
Retrieval-augmented generation, financial document analysis, research summarization, evidence-linked Q&A.

## Guardrail
The LLM is an interpretation layer, not the authoritative source of financial facts.
