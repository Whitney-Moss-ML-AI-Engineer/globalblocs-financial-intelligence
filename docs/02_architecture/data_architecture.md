# Data Architecture

## Layers

**Bronze:** raw API responses, filings, CSV/JSON/XML/XBRL and source documents.

**Silver:** parsed, cleaned, normalized, deduplicated, timestamped, validated records.

**Gold:** financial ratios, economic indicators, market measures, risk measures and engineered features.

**Intelligence:** forecasts, regimes, anomaly scores, risk indicators, model predictions and research outputs.

## Core Entities

Company, Bank, Fund, Security, Bond, Loan, Derivative, Household, Government, Country, Industry, Sector, Event, Filing, Transaction, Regulatory Action.
